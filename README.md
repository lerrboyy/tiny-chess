Tiny Chess is a 4 KB chess engine in pure Python. It uses a 120-square board, alpha-beta search with quiescence, a transposition table, MVV move ordering, and a material plus pawn-advancement evaluation, all under a fixed node budget.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
