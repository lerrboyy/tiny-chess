Tiny Chess is a 4 KB chess engine in pure Python: a sunfish-style 120-square board with piece-square tables, castling, en passant and promotions, alpha-beta search with quiescence, and an iterative-deepening chooser that plays the make.fun tiny-chess-01 gauntlet.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
